# rclone - uso pessoal

Este projeto do Google Cloud existe apenas para que o rclone (https://rclone.org), instalado no computador pessoal do dono desta conta, acesse o proprio Google Drive dele e o monte como uma unidade de disco local.

Nao e um servico publico, nao tem outros usuarios e nao coleta dados de ninguem.
